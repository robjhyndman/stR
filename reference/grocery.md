# Grocery and supermarkets turnover

Turnover of supermarkets and grocery stores in New South Wales,
Australia.

## Usage

``` r
grocery
```

## Format

An object of class `ts`.

## References

Australian Bureau of Statistics, CAT 8501.0. ([TABLE 11. Retail
Turnover, State by Industry Subgroup,
Original](https://www.abs.gov.au/AUSSTATS/abs@.nsf/DetailsPage/8501.0Jun%202016?OpenDocument))

## Examples

``` r
plot(grocery, ylab = "NSW Grocery, $ 10^6")
```
