# Package index

## Functions to fit STR models

- [`AutoSTR()`](https://pkg.robjhyndman.com/stR/reference/AutoSTR.md) :
  Automatic STR decomposition for time series data
- [`STR()`](https://pkg.robjhyndman.com/stR/reference/STR.md) :
  Automatic STR decomposition
- [`STRmodel()`](https://pkg.robjhyndman.com/stR/reference/STRmodel.md)
  : STR decomposition
- [`RSTRmodel()`](https://pkg.robjhyndman.com/stR/reference/RSTRmodel.md)
  : Robust STR decomposition
- [`heuristicSTR()`](https://pkg.robjhyndman.com/stR/reference/heuristicSTR.md)
  : Automatic STR decomposition with heuristic search of the parameters

## Functions that work with STR objects

- [`components()`](https://pkg.robjhyndman.com/stR/reference/components.md)
  : Extract STR components
- [`seasadj(`*`<STR>`*`)`](https://pkg.robjhyndman.com/stR/reference/seasadj.STR.md)
  : Seasonal adjustment based on STR
- [`plot(`*`<STR>`*`)`](https://pkg.robjhyndman.com/stR/reference/plot.STR.md)
  : Plots the results of decomposition
- [`plotBeta()`](https://pkg.robjhyndman.com/stR/reference/plotBeta.md)
  : Plots the varying beta coefficients of decomposition
